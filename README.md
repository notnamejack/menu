# Osteria Alba — меню зала

Меню зала Osteria Alba: антипасти, паста, гриль и десерты, с фото и коротким видео. Данные лежат в `public/data/menu.json`, фото и ролики — в `public/media/`. Админка коммитит правки в репозиторий, GitHub Actions выкладывает сайт на GitHub Pages.

Зал — белый лист, чёрный сериф, строка «название — цена». Подзаголовок: cucina italiana. Цены в рублях. Брони и адреса нет: это меню, не сайт-визитка.

## Меню

Четыре категории, десять блюд. Все опубликованы и в наличии.

- Антипасти: Капрезе, Тартар из лосося
- Паста: Пенне аль рагу, Спагетти карбонара, Ризотто с пармезаном
- Гриль: Лосось на гриле, Полло аль лимоне
- Десерты: Тирамису, Панна-котта, Фисташковое джелато

На плитке: фото, название, цена, короткое описание и вес. В карточке: состав, калории и теги. Если у блюда есть ролик, он играет на фото.

Стоп-лист: в админке выключить **В наличии**. Гость видит серую карточку «Нет в наличии». Скрыть блюдо совсем: выключить **Опубликовано**.

## Локальный запуск

```bash
npm install
npm run dev
```

Откроется `http://localhost:5173/`. Сборка: `npm run build`, превью сборки: `npm run preview`.

Локально `base` в Vite равен `/`. На Pages он `/menu/`: workflow передаёт `BASE_PATH`.

## GitHub Pages

Репозиторий: `notnamejack/menu`. Settings → Pages → Source: **GitHub Actions**. Workflow [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml) запускается на push в `main` и вручную.

Сайт: `https://notnamejack.github.io/menu/`.

Первый деплой иногда просит подтвердить environment `github-pages` в настройках репозитория. После сохранения в админке зал подхватывает новое меню примерно через минуту: запрос к `menu.json` идёт с меткой времени.

## Админка

Отдельная страница, не маршрут гостевого меню:

- локально: `http://localhost:5173/admin/`
- на Pages: `https://notnamejack.github.io/menu/admin/`

В [`public/admin/config.yml`](public/admin/config.yml) репозиторий уже указан: `notnamejack/menu`, ветка `main`.

Токен — fine-grained personal access token:

1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens.
2. Repository access: только `notnamejack/menu`.
3. Permissions → Repository → Contents: Read and write.

На входе Sveltia нажмите **Войти с токеном** и вставьте PAT. Токен хранит браузер в `localStorage`. Интерфейс на русском, если язык браузера русский.

На меню зала есть ссылки **Инструкция** (`/guide/`) и **Для кухни**. В киоске их нет.

Чтобы сменить цену или текст: коллекция **Меню**, список **Блюда**, поле **Цена** — целое число рублей. Новое блюдо: ID латиницей, категория, название, описание, состав, цена, вес, калории, теги, порядок. Фото — WebP или JPG, видео — MP4.

## Киоск

- iPad: Guided Access и меню в Safari или «На экран Домой».
- Android: Fully Kiosk Browser, стартовый URL с `?kiosk=1`.
- Пример: `https://notnamejack.github.io/menu/?kiosk=1`

Режим запоминается в `sessionStorage`. Кнопка **Киоск** делает то же самое. Зоны нажатия от 48px, выделение текста выключено. После 60 секунд без касаний, клавиш и прокрутки закрывается карточка, очищается поиск, страница уезжает наверх, категория сбрасывается на «Всё меню».

Выход: **Закрыть киоск** или адрес с `?kiosk=0`.

## Фото и видео

Фото: WebP или JPG, до 1600 px и около 500 КБ. Видео: MP4 без звука, до 10 секунд и 5 МБ. Пути в данных без ведущего слэша: `media/carbonara.webp`.

720p, без звука, не длиннее 10 секунд. Если файл больше 5 МБ, поднимите `-crf` или укоротите `-t`.

```bash
ffmpeg -y -i input.mp4 -t 10 -an -vf "scale=-2:720" -c:v libx264 -profile:v main -pix_fmt yuv420p -crf 30 -movflags +faststart out.mp4
```

Готовые файлы из папки `eda/` можно пережать командой `npm run media:convert`.
